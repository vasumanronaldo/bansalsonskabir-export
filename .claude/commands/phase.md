Read `docs/05-build-order.md`. Find the first phase whose checkbox is `[ ]`.

Then:
1. Read ONLY the doc(s) that phase names under *Read:*. Do not read the others.
2. State the phase number, what you will build, and any file you expect to overwrite.
3. Build it. Nothing outside that phase's scope.
4. Run the Definition of Done checklist at the foot of `05-build-order.md`.
5. Mark the phase `[x]` in `docs/05-build-order.md`.
6. Commit with a conventional-commit message.
7. Report what you built in under 10 lines, then STOP. Do not start the next phase.
